# ADR 0004: 並べ替えの理由は後から聞き、対象を4条件に限る

## 背景

「なぜこの順番にしたのか」を後から答えられるようにしたい。順序の記録だけでは、判断の理由が残らない。

一方、並べ替えのたびに理由を聞くと手が止まり、並べ替え自体が使われなくなる。

## 決定

理由は**空で記録し、後から聞く**。質問キューに入れるのは次の 4 つだけ。

1. 1 位に上げた
2. 最下位（またはスコープ外）へ落とした
3. スコープ内に期限があるタスクを飛び越えて別を上げた
4. 待ちに 14 日以上置いたまま

3 は自動検知する。並べ替えのイベントに、飛び越えた相手の ID と期限を記録しておく。

隣と入れ替えた等の並べ替えは聞かない。答えなくてもよく、「理由なし」のまま残る。

## 捨てた案

- **ドラッグのたびにモーダルで聞く**: 記録は完全になるが、並べ替えのコストが上がって使われなくなる
- **聞かずに AI が推測する**: 記録は残るが「なぜ」は残らない。推測を根拠として提示することになる

## 変えてよい前提 / 壊すと危ない前提

- **変えてよい**: 4 条件の閾値（待ちの 14 日、スコープの既定 7 日）、質問を出すタイミング
- **壊すと危ない**: 理由が空のまま記録できること。入力を必須にすると並べ替えが止まる
- **壊すと危ない**: 飛び越えた相手を並べ替え時点で記録すること。後から再計算しても、当時の順序と期限は復元できない
