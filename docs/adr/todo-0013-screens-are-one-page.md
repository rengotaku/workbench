# ADR todo-0013: 画面はすべて 1 ページで切り替える（素の JS のルーター、SPA）

todo-order と note-stock の両方の画面に関わる判断だが、番号は todo 側に置く。

## 背景

4 画面（`/`・`/add`・`/notes`・`/notes/timeline`）は、サーバがそれぞれ別の HTML を返していた。上部タブで移るたびにページ全体を読み直すので、todo 一覧で開いていた行とスクロール位置、note 追加に書きかけた文字が消えていた。

各画面の JS は、読み込み時に一度だけ動き、`document` にキー操作を登録したまま外さない作りだった。そのまま 1 ページに同居させると、隠れている画面まで `N` や `Esc` に反応する。タイムラインは Go が HTML を組み立てていて、同じ内容を返す API が無かった。

## 決定

**外枠は 1 枚。** レイアウト（`web/shared/templates/base.html`）が、どのページにも 4 画面のルート要素（`data-view="todo"` など）と、全画面の CSS・JS を置く。サーバの各ページは中身が空で、URL は今までどおり 4 つ残す。`todo` / `note` コマンドが開く URL と、`/#T007`・`/notes/timeline#note-<id>` のリンクはそのまま使える。

**ルーターで切り替える。** `web/shared/static/js/router.js` に画面を `register(name, {title, mount, show, hide})` で登録する。

- 画面の切り替えは `pushState` で行う。戻る・進むにも対応する
- 初めて表示したときに `mount` で自分の HTML を描き、以後は DOM を残して表示・非表示だけを切り替える
- ウィンドウのスクロールは全画面で共有なので、画面ごとに位置を覚えて戻す。同じ画面でクエリだけ変わったとき（タイムラインの絞り込み）は先頭から表示する
- 画面を離れるときは、開いているダイアログを閉じる
- 未登録の画面へは、ページごと読み込む（移行の途中で、画面を 1 つずつ移すために使った）

**隠れている画面は反応しない。** 各画面は自分が表示中かどうか（`active`）を持つ。`document` / `window` へのキー操作・クリックやポーリングは、表示中のときだけ動く。表示し直したときは API から読み直す（todo 一覧、補足待ち、話題、タイムライン）。

**画面は API から描く。** タイムラインは `GET /api/notes/timeline` から描き、本文などは `textContent` で入れる。

**CSS は画面ごとのルート要素の下に絞る。** `:where(.view-…)` でネストし、詳細度は変えない。

**追加ダイアログは画面を貸し出す。** `N` などで開く追加ダイアログは iframe をやめた。ルーターの `lend` が、追加画面のルート要素をダイアログへ一時的に移し、閉じると元の場所に戻す。ダイアログへの通知（保存中・変更あり・閉じたい）は `common.js` の `tell` が直接届ける。`tell('busy')` が返したダイアログにだけ、同じ保存の `changed` / `idle` を届ける。

**ヘッダーは上部に固定する。** タブに手が届かないと、タブを押すために一番上までスクロールした位置が保存されてしまうため。

## 捨てた案

- **React（+ TypeScript + Vite）を入れる**: 状態を残すこと自体に React は要らない。npm とビルド工程が増えるわりに、目的（画面を移っても状態が残る）への効果は素の JS と変わらない
- **状態を `sessionStorage` / `localStorage` に退避し、読み込み時に戻す**: 変更は小さいが、ページの読み直しは残る。残したい状態が増えるたびに、保存と復元を書き足すことになる
- **サーバの HTML を取ってきて差し込む**: Go の組み立てとテストをそのまま使えるが、外枠 1 枚で全画面を JS で描く方針を選んだ。タイムラインは JSON API を新設した
- **追加ダイアログの iframe を残す**: iframe の中で外枠ごと読み込むことになり、書きかけも共有できない
- **隠れた画面の DOM を破棄して作り直す**: 状態が消えるので目的に反する

## 変えてよい前提 / 壊すと危ない前提

- **変えてよい**: 画面の数と URL（`router.js` の `ROUTES` / `NAV` に足す）。表示し直したときに何を読み直すか。ヘッダーの固定
- **壊すと危ない**:
  - 画面のスクリプトが `document` / `window` に足す処理は、必ず `active` を見る。見ないと、隠れた画面がキーに反応したりポーリングしたりする
  - 画面は `mount` の外で DOM を触らない。どのページでも全画面のスクリプトを読み込む
  - CSS は画面のルート要素の外に効かせない。どのページでも全画面の CSS を読み込む
  - ダイアログへの貸し出しは、ダイアログを閉じる前に戻す（`modal.js` は `close` を上書きしてすぐ戻す）。戻す前にルーターが同じ画面を表示すると、閉じかけのダイアログの中に出る
  - 非同期の読み直しは、遅れて届いた古い応答で新しい状態を上書きしない（連番で捨てる、読み始めたあとの保存を消さない）
