# ADR todo-0029: 期限メニューはブラウザ標準の日付欄をやめ、月のカレンダーを最初から出す

## 背景

期限メニューの日付は `<input type="date">` だった。カレンダーはアイコンを押さないと出ず、見づらかった（本人の発言）。また今週の範囲や、期限のあるタスクがある日を、日付欄の上には出せない。

## 決定

**メニューの中に月のカレンダーを最初から出す。** 日のボタンを 7 列に並べ、今日は枠、今の期限は塗り、今週（今日から今週の日曜）は薄い塗り、期限のあるタスクがある日は小さな点で示す。日を押すとその日を期限にして閉じる（通知の文言は従来と同じ）。長期の見直し日のメニューも同じ部品を使う。

後ろにずらす選択肢は `+1日`・`+3日`・`+1週間`・`+2週間`・`+1ヶ月` の 5 つにして横 1 列に並べ、ずらした先の日付を添える。数え方（今日と今の期限の遅い方から）は変えない。

キーボードは、メニューを開くと今の期限の日にフォーカスし、矢印で日を動かし、Enter / Space で決める。格子は `role="grid"` で、各日に「11月12日（木）」の aria-label を付ける。

追加画面の日付選びは、この決定では変えない。

## 捨てた案

- **標準の日付欄を残し、カレンダーを別に足す**: 入力が 2 つになり、どちらが効くか分かりにくい
- **ライブラリのカレンダーを入れる**: ビルド工程を持たない方針（ADR todo-0025）に合わず、今週の塗り・点・矢印キーの動きは自前で書く方が小さい

## 変えてよい前提 / 壊すと危ない前提

- **変えてよい**: 色・大きさ・凡例の文言。ずらす選択肢の数
- **壊すと危ない**:
  - 日付は `YYYY-MM-DD` の文字列で扱い、API に渡す形を変えない
  - 格子の中は矢印キーで日を動かす（メニュー全体の上下矢印の項目移動は、カレンダーの外の項目だけに効く）
  - 開く月は今の期限の月。今の期限と同じ日を押したときは何も送らない
