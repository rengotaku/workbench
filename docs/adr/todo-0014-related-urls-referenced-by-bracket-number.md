# ADR todo-0014: タスクのリンクは関連 URL で持ち、名前から [N] で指す。貼り付けたリンクは関連 URL になる

## 背景

ADR todo-0008 では、名前に貼ったリンクの URL を 1 つだけタスクに保存し（`url`）、名前のうちリンクだった部分（`link_text`）をリンクとして表示していた。note のメモは、本文とは別に関連 URL を何本でも持ち、本文から `[N]` で指す（ADR note-0003）。同じ「リンク付きのテキストを貼る」操作でも、todo と note で残り方が違っていた。todo は 1 本しか持てず、note は貼っても URL を拾わなかった。

## 決定

**タスクは関連 URL を持つ。** `Task.Links`（`[{n, url, label}]`、note の `Link` と同じ形）を足す。名前の `[N]` がそれを指し、画面では `[N]` をその URL へのリンクにする。詳細欄には関連 URL の一覧を出す。

- 追加（`POST /api/tasks` の `links`）と、一覧で開いた行での編集（`PATCH /api/tasks/:id` の `links`。全体を置き換える）で受け取る。番号はサーバが並び順に 1 から振る
- URL は http(s) だけ。一言は任意
- 追加と関連 URL は 1 つのイベント（1 回の undo でタスクごと消える）。編集は `links_set` イベントで、undo で前の一覧に戻る
- 画面で関連 URL を外せるのは、名前がその番号以降を指していないときだけ（外すと後ろの番号が詰まり、`[N]` が別の URL を指してしまうため）。note の登録画面と同じ規則
- CLI は `todo "名前 [1]" --link "URL 一言"`（何度でも指定でき、書いた順に [1] [2] …）。名前に `[N]` は自動で足さない

**貼り付けたリンクは関連 URL になる（todo・note 共通）。** リンク付きのテキストを貼ると、カーソル位置に「テキスト [N]」が入り、関連 URL に URL（一言はリンクの文字）が足される（`web/shared/static/js/paste.js`）。

- リンクが 1 つなら、貼った文字全体の後ろに `[N]` を付ける（キーだけがリンクで件名が横にある、というトラッカーのコピーに合わせる）
- 複数なら、それぞれのリンクの文字の直後に付ける
- 開けるリンク（http/https）だけを拾い、リンクの無いテキストは文字だけが入る
- 貼り付けは編集コマンドで入れ、Cmd+Z で取り消せる

**既存のタスクはそのまま。** `url` / `link_text` を持つタスクは移さず、今までどおり名前の一部をリンクとして表示する。新しく貼ったリンクは関連 URL に入る。

## 捨てた案

- **既存の `url` / `link_text` を関連 URL [1] に移す**: 移行の手間に見合わない。今あるタスクは今の表示のままでよい
- **貼り付けたとき本文に `[N]` を入れず、関連 URL の行に足すだけにする**: どの文字がどの URL を指すかが本文に残らない
- **CLI の `--link` で名前の末尾に `[N]` を自動で足す**: 名前のどこで指すかは書く人が決める
- **関連 URL を登録時だけにする（note と同じ）**: todo は着手まで何度も手を入れるので、一覧で開いた行から足せるようにした

## 変えてよい前提 / 壊すと危ない前提

- **変えてよい**: 関連 URL の上限（今は無い。note も無い）。`[N]` の表示の見た目。CLI のフラグ名
- **壊すと危ない**:
  - 番号は並び順で振る。名前が指している番号の行を外させない規則を、画面から外さない
  - `links` を渡した追加・編集では、`url` / `link_text` を使わない（2 つの方式を 1 つのタスクで混ぜない）
  - 名前の `[N]` は、`links` に同じ番号があるときだけリンクにする。それ以外は文字のまま
