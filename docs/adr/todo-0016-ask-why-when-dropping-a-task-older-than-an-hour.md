# ADR todo-0016: 作ってから1時間以上たったタスクは、画面で消すときに理由を聞く

## 背景

ADR todo-0004 で、削除の理由はクリックの時点では聞かず、空で記録して後から質問キューで聞くことにした。

ところが消したタスクは一覧から無くなり、「今週やめた」も読むだけの区画なので、画面から削除の理由を書く場所が無かった。質問キュー（`GET /api/ask`）に答えられるのは CLI と AI だけで、画面で消した理由は「理由なし」のまま残っていた。

## 決定

- 作ってから 1 時間未満のタスクは、今までどおりゴミ箱を 1 回押すだけで消える（足し間違いをすぐ消すとき）
- 1 時間以上たったタスクは、ゴミ箱を押すと理由の入力欄を出す。何か書くまで消せない。Escape か欄の外を押すと、消さずに閉じる
- 入れた理由は `removed` イベントの `reason` に入る。理由があるので質問キューには出ない
- 必須にするのは画面だけ。`DELETE /api/tasks/:id` は本文の `reason` を任意で受け取り、CLI（`todo rm`）は今までどおり理由なしで消せる

判定は画面がタスクの `created_at` で行う（`app.js` の `ASK_DROP_AFTER_MS`）。

## 捨てた案

- **サーバ側で必須にする**: 1 時間以上たったタスクの削除を、理由なしでは API が断る。CLI や AI の削除まで止まるので採らなかった
- **「今週やめた」の行に理由を書く欄を足す**: 消した後に戻って書くことになり、結局書かれない。消す時点で聞く方が確実
- **全件で理由を聞く**: 足し間違いを消すたびに手が止まる

## 変えてよい前提 / 壊すと危ない前提

- **変えてよい**: 1 時間という閾値（`ASK_DROP_AFTER_MS`）、入力欄の見た目
- **壊すと危ない**: API と CLI で理由なしの削除が通ること。必須にすると CLI と AI の削除が止まる
- **壊すと危ない**: 理由の無い削除は今までどおり質問キューに入ること（todo-0004 のうち、削除以外の部分はそのまま有効）
