# ADR todo-0027: 画面のスコープは暦の週に固定し、切り替えの操作を外す

## 背景

todo 一覧の見出しには、スコープを選ぶボタン（1週間・2週間・すべて・指定）と、指定のときの締め日の欄があった。選んだスコープは localStorage（`todo-order.scope`）に残し、`/api/tasks?scope=` で盤面を読み直していた。画面を全幅にして左にサイドバーを置く作り直し（issue 150）で、見出しの置き場所を整理する必要が出た。

本人の発言では、この切り替えは使っていなかった。

## 決定

**画面のスコープは常に `week`（暦の週）にする。** 切り替えのボタンと「～日付」の欄を画面から外す。localStorage に別のスコープが残っていても読まない。

API とサーバは変えない。`scope` クエリの `2weeks` / `all` / 日数は CLI などから引き続き使える。画面が送らなくなっただけ。

## 捨てた案

- **ボタンを残す（サイドバーなど別の場所へ移す）**: 使っていない操作の置き場所を作ることになり、画面の部品と localStorage の状態が増えたまま残る。使いたくなったときに足せば足りる

## 変えてよい前提 / 壊すと危ない前提

- **変えてよい**: 画面に切り替えを戻すこと。API は今も全スコープを受けるので、画面側の追加だけで済む
- **壊すと危ない**:
  - スコープ外の区画・スコープの境を越えるドラッグ（`scopeDue`）は `scope_days`（応答の値）から境目を出している。固定するのは送る値だけで、この計算は残す
