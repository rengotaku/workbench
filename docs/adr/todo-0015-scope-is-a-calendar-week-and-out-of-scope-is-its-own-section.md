# ADR todo-0015: スコープは暦の週。スコープ外と待ちは畳める区画にする

## 背景

スコープ外の行は着手順の中に畳まれ、トグルで開くと着手順の位置（途中にも混ざる）に出ていた。開閉するとトグルの位置がずれて続けて押せず、どの行がスコープ外かも薄い表示でしか分からなかった。

常に見たいのは「フォーカス」と「今週中にやること」だけで、スコープ外と待ちは必要なときに開けば足りる。一方でスコープの「1 週間」は今日から 7 日で、月曜にスコープ外だった行が火曜にはスコープ内に入る。「今週中」とは一致していなかった。

## 決定

**スコープの 1 週間 / 2 週間は暦の週にする。** 今週の日曜まで / 来週の日曜まで。API は `scope=week` / `scope=2weeks` を受けて日数に直し、既定も `week` にする。日数指定と `all` は残す。

**スコープ外は独立した区画にする。** 着手順の下に「スコープ外」を置き、既定は閉じる。見出しに件数と `期限 M/D 以降` を出す。区画の中は着手順の順を保つ。「待ち」も同じく畳める区画にし、見出しに件数と `最長 N日` を出す。

**区画をまたいでドラッグしたら期限も変える。** 着手順へ入れたらスコープ最終日、スコープ外へ出したらスコープ外の初日にする。落とした区画に留まる日付のうち、元の期限からの変化が一番小さいもの。着手順の位置も落とした場所に合わせて変える。

## 捨てた案

- **スコープ外を着手順の位置に混ぜたまま、トグルを一覧の上に置く**（#66 で一度入れた）: 位置ずれは直るが、常に見たいものだけを出すことにはならない
- **区画をまたぐドラッグを禁止する**: スコープ外の行を今週に入れる操作が、期限チップを開いて日付を選ぶ手順になる
- **区画をまたいでも期限を変えない**: 着手順は変わるが、再描画で元の区画に戻り、落とした場所に見えない

## 変えてよい前提 / 壊すと危ない前提

- **変えてよい**: 区画の順、見出しの文言、ドラッグで付ける日付（いまはスコープの境目の両側）
- **壊すと危ない**: ドラッグの位置を着手順全体に対して「すぐ上の行の次」で送ること（ADR todo-0012）。区画ごとの行数で数えると、もう一方の区画の行の分だけずれる
- **壊すと危ない**: 区画をまたぐドラッグで、並べ替えを先に、期限の変更を後に送ること。並べ替えは読み込んだ時点の revision を持つので、期限を先に変えると revision が進んで並べ替えが拒否される
- **壊すと危ない**: 境目の日付を応答の `scope_days` と `today` から出すこと。ボタンの選択から出すと、行の `in_scope` と食い違うことがある
