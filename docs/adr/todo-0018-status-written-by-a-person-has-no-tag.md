# ADR todo-0018: 人が書く状況には札を付けない

## 背景

ADR todo-0017 で、状況の入力欄の下に札（進んだ / 詰まり / メモ）を置き、選んだ札を補足の種別にした。
使ってみると境目が無かった。「Slack で依頼した」は進んだともメモとも取れる。1 件ごとに選ぶ手間が増え、既定が「進んだ」なので選び忘れると誤った札が付く。札で絞り込みや並べ替えもしていない。

## 決定

- 画面の入力欄から札をなくす。追記は常に `memo`（`actor=human`）で保存する
- 人が書いた `memo` / `progress` / `blocked` には札を出さない。日時と本文だけにする（開いた行・詳細ボックス・一覧の最新 1 行のどれも）
- AI が書いた補足には、種別によらず「AI ○○」の札を出す。人が書いた `quote` / `analysis` には「引用」「考察」の札を残す
- サーバと CLI は `progress` / `blocked` を引き続き受け付ける。受けるだけで害がなく、消すと既存の呼び出しが失敗するため

ADR todo-0017 のうち、「`progress` と `blocked` を足し、`memo` と合わせて人が選べるようにする」を置き換える。それ以外（状況は補足として追記する、待ちは種別にしない）は変えない。

## 捨てた案

- **「詰まり」だけを ON/OFF の印として残す**: 一覧で詰まりを目立たせる使い道がまだ無い。使う場面が出てから足せばよい

## 変えてよい前提 / 壊すと危ない前提

- **変えてよい**: 札を出す種別の組み合わせ（`UNTAGGED_KINDS`）
- **壊すと危ない**: AI の補足に札を出すこと。外すと AI の書き込みを本人の状況と取り違える
