# ADR todo-0005: フォーカスは状態ではなく印として持つ

## 背景

いま手を付けているタスクを画面上部の帯にまとめたい、という要望が出た。

タスクは「着手順」「待ち」「完了」の 3 つの置き場を持つ。フォーカスをここへ 4 つ目として足すと、フォーカスを外したときに元がどこだったかを覚えておく必要が出る。待ちのタスクをフォーカスして外したら着手順へ戻る、といった誤りも起こしやすい。

## 決定

`Task.Focused` を状態とは独立した真偽値として持つ。状態遷移（着手順 ⇄ 待ち ⇄ 完了）には一切関与しない。

画面では、フォーカス中のタスクを上部の帯に出しつつ、**着手順の中にもそのまま残して ◎ を付ける**。順序が正本であり、帯は同じタスクへの 2 つ目の入口にすぎない。

上限は設けない。フォーカスが 0 件のときは帯自体を出さない。

## 捨てた案

- **案 B（帯へ移す）**: 着手順から抜いて上部へ移す。フォーカスを外したとき何番目だったか分からなくなる
- **案 C（モード切替）**: フォーカスだけを表示するモードを設ける。順序を見失う点は案 B と同じで、モードの出入りという操作も増える
- **状態に足す**: 置き場を 4 つにする。戻り先の記憶が必要になり、状態遷移が増える

## 変えてよい前提 / 壊すと危ない前提

- **変えてよい**: 帯の位置・見た目・◎ の記号、フォーカスの件数上限を後から入れること
- **壊すと危ない**: `Focused` が順序と状態に影響しないこと。ここを崩すと「順序が正本」が成立しなくなり、案 B と同じ問題が戻る
