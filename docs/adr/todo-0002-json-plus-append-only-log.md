# ADR todo-0002: 保存は tasks.json と追記専用の JSONL で行い SQLite を使わない

## 背景

扱う件数は数十件。1 台の Mac で動かし、他端末と同期しない。

既存の候補（Taskwarrior 3.x、各種ボイラープレート）は SQLite を前提にしていた。

## 決定

- **状態**: `tasks.json` 1 枚。一時ファイルへ書いて rename で差し替える
- **履歴**: `events-YYYY-MM.jsonl`。追記のみ。月ごとに分ける
- 理由の記録も既存行を書き換えず、同じイベント ID の新しい行を追記する。読み込み時に後の行が前の行を上書きする

## 捨てた案

- **SQLite**: Taskwarrior 3.x が採ったのはマルチデバイス同期のため。1 台 + git の使い方では同期機構のコストだけ払うことになる。中身を目で確認できなくなる不利もある
- **Markdown の台帳**: 置き換える対象がこれ。完了行を物理的にどかす処理が必要になり、順序が別ファイルに割れる

## 変えてよい前提 / 壊すと危ない前提

- **変えてよい**: ログの分割単位（月次 → 週次等）、JSON の項目追加
- **壊すと危ない**: イベントログが追記専用であること。既存行を書き換える実装にすると「そのとき何が起きたか」が失われる
- **壊すと危ない**: `tasks.json` を rename で差し替えること。直接書き込みに変えると、途中で落ちたときに壊れたファイルが残る
